# Privacy Policy
Eyemaster stores limited data used to provide moderation functionality.

*Last updated: July 21, 2026*

## Information Stored
We collect limited Discord-related data strictly for moderation purposes:
- **User IDs**: Unique numerical Discord account identifiers belonging to individuals who receive an infraction, such as a warning, to maintain accurate moderation histories.
- **Staff IDs**: Unique numerical Discord account identifiers belonging to Discord server staff members to track who issued a specific infraction.
- **Server IDs**: Unique numerical Discord server identifiers to track which infractions belong to a specific server.
- **Moderation records**:
    - Reason provided by staff
    - Expiration date (if applicable)
    - Unique warning record ID
    - Timestamp metadata (creation and update dates)
    - Record version metadata
- **Server configuration data**:
    - Moderation log channel ID
    - Moderator role ID

Eyemaster does not intentionally process or persist the contents, embeds, or attachments of messages authored by users or other bots. Administrative tools may retrieve message metadata to locate a requested message, but only process message content or embed data from messages authored by Eyemaster. Eyemaster does not store inbound direct-message data.

Certain commands may temporarily access Discord-provided account or server information to function (for example, commands that fetch information about a user). This information is not stored.

## Purpose of Data Collection
This data is stored solely to:
- Track moderation actions within a server.
- Maintain a history of infractions on a per-user basis.
- Allow server staff to review and enforce moderation decisions consistently.

## Data Sharing
No data is sold to third parties. Data may be processed by infrastructure providers used to host the bot and its database. When an authorized administrator extracts a sufficiently large embed previously sent by Eyemaster, its JSON data may be uploaded to Hastebin to provide the result, which is deleted after 30 days.

## Data Retention
Moderation records are retained while necessary for server moderation and rule enforcement. Authorized staff may update or remove records. Records may also be updated or deleted following a valid data request or when they are no longer necessary.

## Data Access and Deletion Requests
Users may request access to data associated with their account. Authorized server administrators may request server configuration and moderation data they are permitted to manage.

Valid access, correction, and deletion requests will be handled in accordance with applicable law and Discord’s Developer Terms. Subject to applicable law, API data will be deleted following a valid request from the applicable user, if Discord requests deletion, if Eyemaster stops operating, or when it is no longer necessary for Eyemaster’s stated functionality.

## Support
For questions, data requests, or concerns, you may contact the developer via [Support](https://samyeule.github.io/eyemaster_info/support/).
